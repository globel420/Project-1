Where do the pin numbers come from?

Your array is LED_PINS[] = {12, 11, 10, 9, 8}. Index 0 selects D12, the 1s LED at the far right. Index 1 selects D11, the 2s LED. The loop continues through 4, 8, and 16.

bitRead(counter, i) reads one digit from the number stored in binary. Bit 0 is the rightmost digit. A returned 1 means HIGH / ON; 0 means LOW / OFF.

How does this match my Arduino code?
runProjectB() treats a pressed button as true (1) and a released button as false (0). It calculates each logical result, then digitalWrite() turns that result's LED on for true or off for false.
